# Tastenkürzel

| macOS | Windows / Linux | Aktion |
|---|---|---|
| ⌘ 1 | Strg 1 | Projekte |
| ⌘ 2 | Strg 2 | Agentic Control Panel |
| ⌘ 3 oder ⌘ , | Strg 3 oder Strg , | Einstellungen |
| ⌘ W | Strg W | Aktiven Dashboard-Tab schließen |
| ⌘ R | Strg R | Projekte neu scannen |
| ⇧ ⌘ [ / ⇧ ⌘ ] | ⇧ Strg [ / ⇧ Strg ] | Vorheriger / nächster Tab |

Im Dashboard (Vorlage des Projektmanagers): 1–5 Ansichten, I Inspektor, „," Einstellungen, Esc schließen.
