# MGD-DevOS

The central AI Dev OS project hub for ChatGPT Codex, Claude Code and compatible
agents. Start with `/Dashboard`: it reads project rules and the actual Git
state, explains confirmed work, open items and risks, and recommends only
relevant skills or MCP integrations.

It supports new projects, safe migration of existing projects, game and
platform development, staging and backup planning, documentation, dashboards
and skill audits. It never installs skills, connects external services, pushes,
deploys or deletes data without the required user approval.

The included MGD AI-Thread skill provides `/thread` handoffs between Codex and
Claude Code. It saves verified, completed work to the configured Git remote
when the project permits it and records unfinished work honestly.

The local `index.html` dashboard supports system, light and dark modes, tool
accent colors and a browser preference. `SECRETS/` stays protected; `USER
CONCEPT/` keeps source ideas and assets locally.

Read the German [main README](../../README.md) for the complete installation,
safety model, command reference and current release links.
