# MGD-DevOS

La centrale de projet AI Dev OS pour ChatGPT Codex, Claude Code et les agents
compatibles. Commencez avec `/Dashboard` : il lit les règles et l’état réel de
Git, explique les éléments confirmés, ouverts et risqués, puis recommande
uniquement les compétences ou intégrations MCP utiles.

Il gère les nouveaux projets et les projets existants sans installer d’outils,
connecter de services externes, publier, déployer ou supprimer de données sans
autorisation. `SECRETS/` reste protégé et `USER CONCEPT/` conserve les idées et
ressources locales.

Le skill MGD AI-Thread inclus permet de transmettre le travail à Codex ou à
Claude Code avec `/thread`. Il sauvegarde dans Git le travail terminé et
vérifié lorsque le projet l’autorise et signale clairement ce qui reste à faire.

Le guide complet se trouve dans le [README allemand](../../README.md).
