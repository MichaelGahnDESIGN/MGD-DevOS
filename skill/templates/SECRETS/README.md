# Geschützter Bereich: SECRETS

Hier liegen nur lokale Zugangsdaten, personenbezogene Daten und andere sensible
Projektinformationen.

- Nicht in Git, Chats, Screenshots oder öffentliche Dokumentation aufnehmen.
- Agenten dürfen Inhalte nur mit einer konkreten Zustimmung für den genannten
  Pfad lesen, verändern, kopieren oder löschen.
- Für neue Informationen `zugangsdaten.template.md` lokal kopieren und nie
  echte Werte in die Vorlage schreiben.
