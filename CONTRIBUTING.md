# Mitwirken

Änderungen vorschlagen ist ausdrücklich erwünscht: Issue eröffnen oder Pull Request stellen.

## Lizenz

MGD-DevOS steht unter der [PolyForm Noncommercial License 1.0.0](LICENSE): Nutzung, Änderung und
Weitergabe sind für nicht-kommerzielle Zwecke erlaubt, **Verkauf und kommerzielle Nutzung nicht**.
Mit einem Pull Request erklärst du dich einverstanden, dass dein Beitrag unter derselben Lizenz
veröffentlicht wird und dass der Inhaber ihn darüber hinaus verwenden darf.

## Ablauf

1. Fork, Branch, Änderung klein und fokussiert halten.
2. `flutter analyze` und `flutter test` müssen grün sein, neue Funktionen bekommen Tests.
3. Keine Zugangsdaten, Tokens oder Secrets in Code, Tests oder Screenshots.
4. Sicherheitslücken bitte nicht öffentlich melden, sondern privat an den Repository-Inhaber.
