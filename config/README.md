# Laufzeit-Konfiguration

`mgd-devos-config.json` ist öffentlich und enthält nur nicht-sensible Werte (Titel, URLs, Schalter).
Abruf: `https://raw.githubusercontent.com/MichaelGahnDESIGN/MGD-DevOS/main/config/mgd-devos-config.json`.
`target_url` und `stripe_donation_url` sind leer, bis es eine Web-Version bzw. einen geprüften Spendenlink gibt.
